# Ритм — Telegram Mini App

Мінімальний прототип застосунку для контролю харчування та дефіциту калорій.

## Запуск

Node.js не потрібен для перегляду прототипу: відкрийте `index.html` у браузері або опублікуйте папку на будь-якому статичному хостингу.

Для підключення до Telegram Bot API вкажіть URL опублікованого `index.html` у кнопці Web App вашого бота.

## Що вже працює

- анкета: стать, вік, зріст, вага, активність і мета;
- орієнтовний розрахунок BMR/TDEE за Mifflin-St Jeor;
- ціль калорій для схуднення, підтримки ваги або набору м’язів із помірним профіцитом 8%;
- автоматичний розподіл калорій між сніданком, обідом і вечерею;
- рекомендації з грамами продуктів у сирому вигляді;
- каталог із 38 продуктів, точними рекомендованими грамами та калорійністю на 100 г;
- ротація рекомендацій за локальною датою;
- цілі білків, жирів і вуглеводів; для набору м’язів білок розраховується як 1,8 г/кг;
- збереження профілю в `localStorage`;
- базова інтеграція Telegram WebApp.

Це орієнтовний wellness-розрахунок, а не медична рекомендація.
